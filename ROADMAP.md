# JARVIS Product & Technical Roadmap

## Milestones

- [x] **v0.1 Foundation**
  - Abstract Interfaces & Type Contracts
  - Async Event Bus with Event Store & Correlation IDs
  - State Machine (`StateManager`)
  - Subsystem Lifecycle Manager (`ServiceManager` with Auto-Recovery)
  - Observability Suite (`logger`, `metrics`, `tracing`, `diagnostics`)
  - Dynamic Configuration Profiles (`Developer`, `Gaming`, `Study`, `Laptop`, `Desktop`)

- [x] **v0.2 Speech & Multilingual**
  - Speech Orchestrator (`SpeechManager`)
  - Code-Switching Multilingual Manager (`LanguageManager`)
  - STT Provider & TTS Voice Adapters

- [x] **v0.3 Executive Agent & Brain**
  - Executive Agent & Decision Engine
  - Intent Classifier
  - Execution Plan Generator

- [x] **v0.4 Automation & Capability Discovery**
  - Tool Registry with Capability Discovery (`find_by_capability`)
  - Async Action Queue (`PENDING`, `RUNNING`, `PAUSED`, `FAILED`, `COMPLETED`)
  - Automation Executor & Undo Transaction Manager

- [x] **v0.5 Memory & Context**
  - Tagged & Timed Memory System (`MemoryManager`)
  - Session Manager & Archival
  - Runtime Context Snapshot Manager

- [x] **v0.6 Desktop UI Dashboard**
  - PySide6 Dark Glassmorphic GUI Application
  - Live Event Timeline & Event Store Inspector
  - Subsystem Dependency Graph Status Monitor

- [x] **v0.7 Vision & MCP Layer**
  - Model Context Protocol (MCP) Client & Tool Adapters
  - Vision & Desktop Inspectors

- [x] **v0.8 Benchmarks & Evaluation Framework**
  - Benchmarking Suite (Latency, Tool Speed, Memory Retrieval)
  - Quality Evaluator (Tool Selection, Plan Optimality)

- [ ] **v1.0 Stable Release**
  - Final hardware optimization & deployment.
